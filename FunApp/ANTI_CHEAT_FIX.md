# ? Anti-Cheating Fix - Hide Unrevealed Words

## Problem
When you add words to the Spell the Word game, they appear in **both**:
1. ? Manage Words panel (good - this is for admin only)
2. ? Score Board table (bad - participants can see them!)

This allows participants to cheat by seeing all words before they're revealed.

## The Fix

### What Changed
**Updated `SpellWord.cshtml`** - Modified the `renderScoreTable()` function:

**Before:**
```javascript
// Showed ALL words (blurred if not revealed)
allWords.forEach(word => {
    // Shows every word with blur-sm class for unrevealed
});
```

**After:**
```javascript
// Only shows REVEALED words
const revealedWords = allWords.filter(w => w.isRevealed);

if (revealedWords.length === 0) {
    tbody.innerHTML = '<tr><td colspan="3" class="text-center py-4 text-white/70">No words revealed yet</td></tr>';
    return;
}

revealedWords.forEach(word => {
    // Only revealed words appear in the table
});
```
