## When to Add Words

### Best Practice - Add Before Game Starts
```
Timeline:
1. Before participants arrive
   ?
2. Admin adds all words
   ?
3. Admin navigates to SpellWord page
   ?
4. Score Board shows "No words revealed yet"
   ?
5. Participants arrive
   ?
6. Start revealing words one by one
```

### If Adding During Game
1. Make sure screen is not visible to participants
2. Or use a separate admin screen/device
3. Or briefly blank the projector

// NEW CODE (only revealed words)

    // Only revealed words appear
