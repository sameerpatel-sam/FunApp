## ?? What Happens Step by Step

### Step 1: You Run the Script
```
.\run-ngrok.ps1
     ?
     ??? Starts your ASP.NET app on localhost:5000
     ?
     ??? Starts ngrok tunnel
```

### Step 2: ngrok Creates Public URL
```
ngrok connects to ngrok.com
     ?
     ??? Gets assigned: https://abc123.ngrok-free.app
     ?
     ??? Forwards all traffic to your localhost:5000
```

### Step 3: Participants Connect
```
Participant opens: https://abc123.ngrok-free.app
     ?
     ??? Request goes to ngrok.com servers
     ?
     ??? ngrok.com forwards to your ngrok client
     ?
     ??? Your ngrok forwards to localhost:5000
     ?
     ??? Your app handles the request and responds
```

## ?? Pro Tips

### Tip 1: Bookmark ngrok Dashboard
```
http://localhost:4040
```
This shows:
- All incoming requests
- Response times
- Connection count
- Tunnel status

### Tip 2: Share QR Code
Generate a QR code for your ngrok URL:
1. Go to https://qr-code-generator.com/
2. Enter your ngrok URL
3. Generate QR code
4. Show on screen - participants scan to join!

### Tip 3: Test Before Sharing
```
1. Run .\run-ngrok.ps1
2. Open ngrok URL on YOUR phone
3. Test joining as participant
4. Verify everything works
5. THEN share with others
```

### Tip 4: Keep Windows Visible
Position your screen so you can see:
- Browser (host view)
- dotnet window (logs)
- ngrok window (connections)

## ?? Common Pitfalls

### Pitfall 1: Closing the Terminal
```
? DON'T close the PowerShell windows!
   Your tunnel will disconnect
   
? Minimize them instead
```

### Pitfall 2: Forgetting to Restart
```
? Making code changes while app is running
   Changes won't apply!
   
? Close windows ? Run script again
```

### Pitfall 3: Wrong URL
```
? Sharing http://localhost:5000
   Only works on your computer!
   
? Share https://abc123.ngrok-free.app
   Works from anywhere!
```

## ?? If Something Goes Wrong

### App won't start?
```
Check dotnet window for errors
Common: Database migration needed
Fix: dotnet ef database update
```

### ngrok won't connect?
```
Check ngrok window for errors
Common: Authentication required
Fix: Add your authtoken
```

### Participants can't connect?
```
Check:
1. Is app running? (dotnet window)
2. Is ngrok running? (ngrok window)
3. Did you share the right URL?
4. Is URL still valid? (check ngrok window)
```
